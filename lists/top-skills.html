세부 보기

mukul975 / Anthropic-Cybersecurity-Skills

This repository provides 754 structured cybersecurity skills mapped to industry standards like MITRE ATT&CK and NIST CSF 2.0. It enables Hermes to operate across 26 security domains, including malware analysis and cloud security, using the agentskills.io integration standard.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI patterns using a tiered 109-entry word replacement table. It features a two-pass audit system compatible with Hermes Agent to ensure natural-sounding, human-like text generation.

wondelai / skills

A cross-platform library that provides modular skills for architecture, UX design, and product strategy via a dedicated CLI. It allows Hermes to quickly adopt professional frameworks through an npx-based marketplace compatible with the agentskills.io standard.

Agents365-ai / drawio-skill

This skill enables Hermes to generate six types of professional diagrams, including UML and ML architectures, directly from natural language. It features a five-round self-check safety valve and coordinate snapping to ensure precise, grid-aligned visual outputs.

DougTrajano / pydantic-ai-skills

This project implements the Agent Skills open specification for Pydantic AI with a focus on type safety and token efficiency. It uses progressive disclosure of metadata to reduce context usage while supporting both filesystem and programmatic skill definitions.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that monitors active workflows to automatically detect and propose new, reusable skills. It generates both Python scaffolds and documentation, allowing Hermes to autonomously expand its own capabilities via slash commands.

tlehman / litprog-skill

This literate programming tool allows Hermes to weave together prose, diagrams, and source code into unified .lit.md files. It includes a tangler to extract runnable code and automatically syncs edits between documentation and source files.

esaradev / icarus-plugin

Icarus provides Hermes with cross-instance shared memory and a pipeline for training its own replacement models. It extracts decision-quality data from active workflows into markdown-based fabric directories for fine-tuning and evaluation.

ReinaMacCredy / maestro

Maestro is an orchestration harness that manages long-running missions through structured milestones and validation assertions. It persists agent state locally, allowing Hermes to hand off complex tasks to other models using generated markdown briefs.

smartcontractkit / chainlink-agent-skills

Designed for blockchain interoperability, this skill set allows agents to perform CCIP cross-chain sends and monitor multi-chain data feeds. It follows the agentskills.io spec to provide Hermes with standardized smart contract interaction and local testing capabilities.

chigwell / skilldock.io

This registry offers an OpenAPI-driven SDK for managing the lifecycle of reusable AI skills with built-in monetization via Stripe and TON. It simplifies Hermes' expansion by handling automated dependency resolution and local skill installation.

black-forest-labs / skills

These official skills provide standardized prompting guidelines and API integration patterns for the FLUX.1 and FLUX.2 image generation models. They enable Hermes to utilize precise hex colors and structured JSON prompting for high-fidelity visual tasks.

amanning3390 / hermeshub

A community-driven hub for browsing and installing skills that features automated security scanning for prompt injection and data exfiltration. It supports micropayment protocols for premium content and an agent-to-agent feedback system based on proof-of-use.

armelhbobdad / bmad-module-skill-forge

This forge converts existing code repositories and developer documentation into version-pinned, agentskills.io-compliant instructions. It provides verifiable audit trails with file-and-line level provenance to ensure the reliability of generated agent skills.

tiann / execplan-skill

This skill facilitates the autonomous execution of multi-step tasks with real-time progress tracking and decision logging. It includes built-in rollback procedures and checkpoints to ensure Hermes can safely recover from errors during long-running operations.

cablate / Agentic-MCP-Skill

This progressive Model Context Protocol client uses three-layer lazy loading to significantly reduce token consumption. It maintains persistent server connections via a socket-based daemon and supports hot-reloading for seamless configuration updates.

PederHP / skillsdotnet

This C# implementation of the agentskills.io specification brings MCP integration to the .NET ecosystem. It supports automatic skill discovery and utilizes progressive disclosure to save tokens when Hermes interacts with .NET-based tools.
