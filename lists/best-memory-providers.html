세부 보기

garrytan / gbrain

A self-wiring knowledge graph that automates the ingestion of emails, meetings, and voice calls without requiring LLM calls for entity linking. It is a powerful choice for users seeking deep integration via MCP servers for tools like Claude Code and Cursor.

vectorize-io / hindsight

This system implements biomimetic data structures to facilitate long-term agent learning through dedicated retain, recall, and reflect workflows. It offers broad compatibility by integrating with OpenAI, Anthropic, and Ollama.

greyhaven-ai / autocontext

A recursive context harness that utilizes a multi-agent loop of specialized roles, such as analysts and architects, to accumulate validated knowledge. It is designed to improve performance on complex, repeated tasks through verifier-driven checkpoints.

stephenschoettler / hermes-lcm

A lossless context engine that uses a hierarchical DAG structure and immutable SQLite storage to ensure no conversation history is ever deleted. It features a three-level escalation mechanism to guarantee context convergence during complex interactions.

elkimek / honcho-self-hosted

This backend provides a private, self-hosted solution for cross-session memory persistence. It is optimized for local control, supporting any OpenAI-compatible provider and featuring automated setup via Docker, PostgreSQL, and Redis.

yoloshii / ClawMem

A local-first, on-device memory engine that utilizes a unified SQLite vault to maintain persistence across different agents. It employs a hybrid retrieval strategy combining vector search, BM25, and graph traversal for robust context access.

plur-ai / plur

A shared memory layer designed for multi-agent systems that utilizes an open YAML engram format for local storage. It enables zero-cost retrieval through hybrid search and automates memory injection for Hermes and MCP tools.

AxDSan / mnemosyne

A high-performance, zero-dependency memory system providing sub-millisecond latency through SQLite-native vector search. It organizes information into a three-tier BEAM architecture consisting of working, episodic, and scratchpad memory.

keepnotes-ai / keep

This reflective memory system indexes codebases and media using automatic summarization and OCR. It uses edge tags to build bidirectional relationships between notes, accessible via MCP and CLI interfaces.

amanning3390 / flowstate-qmd

An anticipatory memory system that prefetches context by monitoring agent session logs. It is a local-first solution using SQLite-vec and GGUF models, featuring an MCP-native server for seamless integration with coding agents.
