세부 보기

nesquena / hermes-webui

A zero-build web interface that provides full feature parity with the Hermes Agent CLI. It utilizes a three-panel layout to streamline chat, file browsing, and session management across desktop and mobile browsers.

outsourc-e / hermes-workspace

A security-hardened native web workspace featuring execution approval prompts and auth middleware. It offers deep orchestration tools, including a dedicated skills manager and a comprehensive memory browser.

EKKOLearnAI / hermes-web-ui

A comprehensive dashboard focused on multi-platform connectivity and operational oversight. It features unified configuration for channels like Telegram and Discord, alongside real-time usage analytics for token consumption and costs.

dodo-reach / hermes-desktop

A native macOS application that connects directly via SSH without requiring a remote helper service. It provides a professional multi-tabbed terminal with live theme controls for managing sessions and cron jobs.

xaspx / hermes-control-interface

A self-hosted gateway designed for managing multiple agent profiles from a single dashboard. It combines a browser-based terminal and system metrics with detailed token analytics categorized by model and platform.

fathah / hermes-desktop

A desktop companion app that simplifies the onboarding process through guided installation and dependency resolution. It supports a wide array of LLM providers and local endpoints alongside integrated messaging gateways.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA specifically designed as a Telegram Mini App. It enables background agent spawning with live output monitoring and integrated system health gauges for hardware resources.

Web3CZ / Web3Hermes

A localized Chinese version of the Hermes WebUI tailored for accessibility within the Chinese community. It includes a workspace file browser for direct editing and tool call visualization within session management.

sanchomuzax / hermes-webui

A specialized monitoring dashboard focused on process oversight and configuration. It features FTS5 search for conversation history inspection and real-time tracking of cost distribution.

pyrate-llama / hermes-ui

A glassmorphic React 18 interface built on a single-file architecture. It features a multi-tab terminal that supports simultaneous Shell, Hermes, and Claude Code workflows.

Euraika-Labs / pan-ui

A self-hosted workspace that integrates a marketplace for MCP servers, plugins, and skills.sh, utilizing isolated profile management to separate sessions, memory, and API keys.
