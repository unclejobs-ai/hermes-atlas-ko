세부 보기

builderz-labs / mission-control

This self-hosted orchestration platform manages multi-agent workflows across frameworks like CrewAI and AutoGen using a zero-dependency SQLite backend. It is essential for Hermes users who require cost monitoring and a human-in-the-loop 'Aegis' system for manual task sign-off.

swarmclawai / swarmclaw

Swarmclaw provides a self-hosted runtime for building autonomous agent swarms with native support for Hermes and 22 other model providers. It stands out by offering MCP-native skills, persistent memory, and scheduled heartbeats to maintain long-running agent delegations.

howdymary / hermes-agent-metaharness

This project implements a meta-optimization harness that uses an automated outer-loop search to refine the code used for evaluating Hermes. It orchestrates TBLite and TB2 benchmarks, tracking performance frontiers through structured candidate mutation and comparison.

1ilkhamov / opencode-hermes-multiagent

This framework coordinates a massive fleet of 17 specialized agents across distinct development phases from research to infrastructure. It ensures high-fidelity outputs by enforcing mandatory quality gates for code reviews and testing across multiple LLM backends.

runtimenoteslabs / gladiator

Gladiator creates a competitive arena where two autonomous AI companies, powered by Hermes Agent and Paperclip, vie for GitHub stars. The framework orchestrates nine specialized agents and visualizes their real-time tasks, code generation, and scoreboard metrics on a live dashboard.

supermodeltools / bigiron

Bigiron automates an eight-phase software development lifecycle by providing Hermes with structural code graphs via the Supermodel MCP. It differentiates itself by using graph-diff phase gates to enforce architectural integrity throughout the autonomous coding process.

Rainhoole / hermes-agent-acp-skill

This delegation tool routes tasks between Hermes subagents, Codex, and Claude Code while preventing context pollution in the parent agent. It prioritizes operational safety by implementing isolated workflows with configurable timeouts and strict output character limits.
