세부 보기

numtide / llm-agents.nix

This project provides reproducible Nix packages for Hermes and other AI coding agents, ensuring consistent environments across different machines. It features automated daily updates and supports direct execution via Nix flakes, allowing users to run the latest version of Hermes without a traditional installation.

rookiemann / portable-hermes-agent

Designed for Windows users, this zero-install desktop agent provides a GUI and over 100 built-in tools without requiring Docker. It supports local model execution via LM Studio and includes a dynamic tool maker for building custom automation pipelines and workflows.

TheAiSingularity / hermesclaw

Focused on high-security environments, this project implements hardware-enforced sandboxing using NVIDIA OpenShell and kernel-level syscall blocking. It includes a library of over 40 integrated tools and offers pre-configured security policies that range from strict inference to permissive system access.

xmbshwll / hermes-agent-docker

This project provides a streamlined Docker-based sandbox that includes both the official Hermes installation and mini-swe-agent. It supports persistent state through mounted directories and allows users to target specific Hermes versions using build arguments.

0xrsydn / nix-hermes-agent

This repository offers a NixOS module for declarative management of Hermes configurations, documents, and systemd services. It prioritizes security through sops-nix integration for secrets handling and supports a hybrid skill model that combines Nix-managed tools with interactive CLI installs.

JackTheGit / hermes-autonomous-server

Targeting production environments on Ubuntu and Debian, this deployment configures the Hermes Gateway as a reboot-safe systemd service. It is optimized for headless operation and enables the execution of autonomous, recurring AI cron jobs through Nous Portal integration.

ellickjohnson / portainer-stack-hermes

This deployment option uses Docker Compose to provide a web-accessible Hermes agent via a ttyd terminal interface. It is designed to integrate directly with Portainer as a Git Repository stack and utilizes GitHub Actions for automated image builds.
